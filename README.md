# Nyxion Heredity Plugin Registry

本仓库是 `Nyxion-Heredity` 的官方插件索引库。我们在索引中提供插件的元数据、下载链接和哈希校验值。

## ⚠️ 免责声明 (Disclaimer)
**本仓库仅作为插件索引目录，不直接托管任何插件代码。**
所有插件的运行结果与法律责任均由插件作者承担。Nyxion 官方不提供、也不审查任何针对特定第三方平台的私有协议破解实现。因使用本仓库索引中的插件导致的账号封禁或法律纠纷，官方概不负责。

## 🚀 如何提交你的插件？

1. 在你的 GitHub 仓库中完成插件开发，并在 `Releases` 中打包成zip发布。
2. 计算你发布包的 `SHA256` 哈希值。
3. `Fork` 本仓库。
4. 编辑根目录下的 `plugins.json`，在 `plugins` 数组中添加你的插件元数据（请参考现有格式）。
5. 提交 Pull Request (PR)。通过自动化格式校验后，管理员将进行合并。

## 🛡️ 开发规范
*   **接口声明**：插件必须在代码中显式声明其注入总线的标识符。
*   **零越权**：严禁插件试图 Hook 或访问其他插件命名空间下的数据。
*   **安全合规**：坚决禁止提交违规、恶意或传播计算机病毒的代码。
