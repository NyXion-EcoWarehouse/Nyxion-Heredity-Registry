# Nyxion Heredity Plugin Registry

> 这是 Nyxion 生态中 `Nyxion-Heredity` 宿主程序的官方与社区插件索引库。

本仓库不托管任何具体的插件源代码，仅作为元数据（Metadata）索引目录。`Nyxion-Heredity` 客户端会拉取本仓库的 `plugins.json` 文件，以渲染“插件市场”列表。

## ⚠️ 法律免责与安全声明 (Legal Disclaimer & Safety)

1. **仅提供索引**：本仓库仅存储插件的下载链接、版本信息与哈希校验值，绝不包含、不托管、也不审查任何针对特定第三方通讯平台的私有协议破解或逆向代码。
2. **第三方风险**：所有收录的插件均由独立开发者提供。因使用第三方插件导致的任何外部账号封禁、数据泄露、系统崩溃或法律纠纷，**Nyxion 官方及本仓库维护者不承担任何连带责任**。
3. **使用者自负其责**：用户应自行评估插件的安全性与合规性，并在沙盒或备用环境中进行测试。

## 🚀 如何提交你的插件 (How to Submit)

如果你开发了基于 `Nyxion-Heredity` 的插件，欢迎提交 PR 将其加入索引：

1. **发布你的插件**：在你的 GitHub 仓库中，使用 `Releases` 功能打包并发布你的插件（支持 `.wasm` 或 `.zip` 格式）。
2. **获取哈希值**：计算你发布包的 `SHA256` 哈希值。
3. **Fork 本仓库**：点击右上角的 Fork。
4. **修改 `plugins.json`**：在文件末尾的 `plugins` 数组中，添加你的插件元数据（请严格参考现有的 JSON 格式）。
5. **发起 Pull Request**：提交 PR，等待自动化 CI 校验与管理员审核。

## 🛡️ 插件开发规范

*   插件必须实现 `Nyxion-Heredity` 官方 SDK 规定的生命周期接口（如 `onLoad`, `onEnable`, `emitEvent`）。
*   插件在注入总线时，必须使用其独立的命名空间，**严禁访问或篡改其他插件命名空间下的数据**。
*   **禁止**提交包含恶意代码、后门、或未经用户授权收集隐私数据的插件。
